Failed overlap children use the existing zero-update native reconciliation only when the exact target and running digest are stable. GitHub retains approval history per run; a rerun now accepts repeated approval by the same independent reviewer while the current protected job must pass its own approval step. Conflicting reviewers fail closed. This behavior has synthetic tests but no non-production protected-environment rehearsal.
3. **Artifact-signing bootstrap is deliberately fail closed at an unrecoverable partial key state.** `production-artifact-signing-secrets-adapter.mjs` now supplies a deterministic 64-character client request token, verifies the native `VersionId`, and reads back that exact version and value. `production-artifact-signing-domain.mjs` reuses a persisted private key after a lost response, while a partial domain with no recoverable private key stops instead of generating another key. The first in-memory key generation still has no separately governed durable escrow before its first write. A lost response with no authoritative version readback remains `OUTCOME_UNKNOWN`; separate authorized reconciliation is required. This is a deployment recovery limit, not permission to regenerate a key from an ambiguous state.
