## Printer disabled-route sign-off

Browser-mediated print pack download and direct-print render-token resolution are intentionally disabled with `410` responses. Existing and Phase E2 tests prove safe JSON responses and no tenant/token markers. Before enabling artifact downloads, add positive tests for scoped pack download, render-token expiry, single-use behavior, filename metadata, connector/printer claim, and content parsing.
