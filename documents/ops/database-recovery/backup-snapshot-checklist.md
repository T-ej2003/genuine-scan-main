# Backup And Snapshot Checklist

Last updated: 2026-05-11

## Checklist

- [ ] Automated backups are enabled.
- [ ] Snapshot retention is configured and meets business requirements.
- [ ] Latest successful backup time is recorded.
- [ ] Manual snapshot creation process is documented.
- [ ] Cross-region snapshot copy option is confirmed.
- [ ] Encryption/KMS access is confirmed in the target region.
- [ ] Restore permissions are confirmed for the database operator.
- [ ] Backup age is recorded.
- [ ] Acceptable RPO is defined.
- [ ] Backup restore test has been scheduled or completed.
