# MSCQR Connector Security Notice

LEGAL REVIEW REQUIRED BEFORE EXTERNAL PRODUCTION RELEASE

Install the MSCQR Connector only from the official MSCQR connector download page or an approved MSCQR release channel.

For production Windows factories, use the signed Windows installer. Do not bypass Smart App Control or Windows security prompts for unsigned connector packages.

The connector verifies printer route readiness, connector capabilities, and setup-test-label proof before production printing can proceed. These checks protect QR identity, batch release integrity, and physical print proof.

Report unexpected publisher names, invalid signatures, or unrecognised connector files to MSCQR support before installation.
