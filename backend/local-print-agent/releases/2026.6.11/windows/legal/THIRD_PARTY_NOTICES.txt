# MSCQR Connector Third Party Notices

LEGAL REVIEW REQUIRED BEFORE EXTERNAL PRODUCTION RELEASE

The MSCQR Connector includes runtime components and open-source dependencies used by the MSCQR backend local print agent.

Dependency notices and software bill of materials are generated during release validation. The signed Windows release output should include the generated SBOM and checksum files when produced by the release workflow.

Customers should retain this notice with the installed connector package for audit and compliance review.
