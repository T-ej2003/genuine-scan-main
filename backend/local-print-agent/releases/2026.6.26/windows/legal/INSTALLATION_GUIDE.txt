# MSCQR Connector Installation Guide

LEGAL REVIEW REQUIRED BEFORE EXTERNAL PRODUCTION RELEASE

1. Open the MSCQR connector download page on the Windows computer connected to the label printer.
2. Download the signed Windows connector installer.
3. Confirm Windows shows the expected MSCQR publisher before continuing.
4. Run the installer once.
5. Return to MSCQR Printer Setup.
6. Select the working printer route.
7. Print and physically confirm the setup test label before production printing.

Do not use unsigned test ZIP packages for production factory rollout.
